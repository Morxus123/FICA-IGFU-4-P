# FICA–IGF-U v4.1 — Domain Engines

v4.1 moves beyond domain registration: every major domain family now has representative executable primitives behind a common `/api/science/engine/run` interface.

Examples:
- mathematics: GCD, polynomial evaluation
- computer science: graph statistics, complexity-family notation
- physical sciences: kinetic energy, Ohm's law
- chemistry: molarity, simple balance check
- Earth/environment: density, temperature anomaly
- biology: exponential growth, allele frequency
- engineering: stress, RC time constant
- medical/health: BMI, sensitivity/specificity
- agriculture/veterinary: yield/area, feed conversion ratio
- social sciences: mean, response rate
- humanities/arts: text statistics, argument-structure check

These are executable, deterministic, bounded primitives. They are not a claim that each field has been fully automated.
