# Full scope and epistemic boundary

The requested "all sciences, ready in full" is interpreted in the strongest scientifically defensible way:

1. all major R&D field families are represented;
2. subfields have registered vocabularies;
3. all domains use the same kernel, graph, provenance and certificate mechanisms;
4. each domain exposes primitive validation/description operations;
5. the system is extensible without changing the core;
6. no domain is falsely advertised as having a complete autonomous solver.

A platform that claimed to contain every theory, method, instrument model, experimental protocol and solver for every scientific subfield would be making a false completeness claim.

The v4.0 design therefore makes "complete framework" a testable software property and leaves domain-specific scientific truth to specialized, reviewable modules.
